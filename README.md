# Undo & Redo Simulator (Java OOP)

A console-based Undo/Redo simulator built in Java using Object-Oriented Programming principles (Encapsulation, Abstraction, Polymorphism, Generics, and the Command Design Pattern).

## How to Run
```bash
javac -d out src/com/editor/model/*.java src/com/editor/action/*.java src/com/editor/manager/*.java src/com/editor/*.java
java -cp out src.com.editor.Main
